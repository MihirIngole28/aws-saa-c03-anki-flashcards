CloudFormation – exam angle?	Infrastructure as Code (JSON/YAML). Reproducible infrastructure, drift detection, nested stacks, StackSets for multi-account/region.	Other
CDK – what is it?	Infrastructure as Code using programming languages (TypeScript, Python, Java). Compiles to CloudFormation; more developer-friendly.	Other
Elastic Beanstalk – when to use?	PaaS: upload code and AWS manages the infrastructure (EC2, ASG, ELB, RDS). Good for developers; not for complex architectures.	Other
Systems Manager (SSM) – key features?	Operational management of EC2/on-prem. Run Command (scripts without SSH), Patch Manager, Session Manager (browser-based SSH without opening port 22), Parameter Store.	Other
AWS Organizations – key features?	Centrally manage multiple accounts. Service Control Policies (SCPs) restrict member accounts; consolidated billing; OU hierarchy.	Other
Control Tower – purpose?	Set up a multi-account landing zone with guardrails. Uses Organizations + SSO + Config + CloudTrail; Account Factory for vending new accounts.	Other
Trusted Advisor – what it checks?	Best-practice checks across Cost Optimization, Performance, Security, Fault Tolerance, Service Limits. Full checks require Business/Enterprise support.	Other
Cognito User Pools vs Identity Pools?	User Pools = user directory + authentication (sign-up/sign-in, MFA). Outputs JWT tokens.<br>Identity Pools = exchange tokens for temporary AWS credentials (STS). Gives access to AWS services.	Other Cognito
Global Accelerator vs CloudFront – quick distinction?	Global Accelerator = static anycast IPs + routes TCP/UDP via AWS backbone to nearest healthy endpoint (gaming, IoT, non-HTTP).<br>CloudFront = CDN that caches HTTP/HTTPS content at edge locations.	Other
Outposts / Wavelength / Local Zones – one-line purpose?	Outposts: AWS hardware in your data center (low latency / data residency).<br>Wavelength: AWS in telecom 5G networks (ultra-low latency to mobile devices).<br>Local Zones: AWS infrastructure in metro areas outside main regions (single-digit ms to specific cities).	Other
Global Accelerator vs CloudFront – key comparison points?	Caching: GA = No; CloudFront = Yes.<br>Protocol: GA = any TCP/UDP; CloudFront = HTTP/HTTPS/WebSocket.<br>IPs: GA = 2 static anycast IPs; CloudFront = dynamic.<br>Best for: GA = gaming/IoT/VoIP/non-HTTP failover; CloudFront = web apps, media, static/dynamic content.	Confusion
SQS vs SNS vs Kinesis – quick comparison?	SQS: Queue (pull); 14 days persistence; best-effort/FIFO ordering; no replay; worker pools.<br>SNS: Pub/Sub (push); no persistence; no ordering; fan-out notifications.<br>Kinesis: Stream (pull); 1–365 days; ordered within shard; replay; real-time analytics/IoT.	Confusion
EBS vs EFS vs S3 – core differences?	EBS: Block; single EC2 (or Multi-Attach same AZ); single AZ; OS/boot/databases.<br>EFS: File (NFS); many EC2 across AZs (Linux); multi-AZ; shared files.<br>S3: Object; HTTP access; regional/global; backups, static sites, data lakes. Cannot mount natively.	Confusion
RDS Multi-AZ vs Aurora Multi-AZ vs Aurora Global DB?	RDS Multi-AZ: ~1–2 min failover; secondary not readable; 1 region, 2 AZs; HA in region.<br>Aurora Multi-AZ: < 30 s failover; up to 15 readable replicas; 1 region, 3 AZs; HA + reads.<br>Aurora Global: < 1 min regional failover; local reads; multi-region; global DR + local reads.	Confusion
CloudWatch vs CloudTrail vs Config vs Trusted Advisor?	CloudWatch → How is my app PERFORMING? (metrics/logs)<br>CloudTrail → WHO called what API WHEN? (audit)<br>Config → Is my infrastructure COMPLIANT? (configuration)<br>Trusted Advisor → Am I following BEST PRACTICES? (recommendations)	Confusion
Cognito User Pool vs Identity Pool – exam scenarios?	“User login for web/mobile app” → User Pool.<br>“Users need direct access to S3 / DynamoDB from mobile app” → Identity Pool (gives temporary AWS credentials).	Confusion Cognito
Direct Connect vs VPN vs PrivateLink vs Peering / TGW?	VPN: Encrypted over internet; fast setup; variable latency.<br>Direct Connect: Dedicated private line; consistent, high bandwidth.<br>Peering: Direct VPC-to-VPC; non-transitive; no overlapping CIDR.<br>Transit Gateway: Hub-and-spoke for many VPCs + on-prem; transitive.<br>PrivateLink: Expose one service without full VPC access (SaaS pattern).<br>VPC Endpoints: Private access to AWS services (Gateway = free for S3/DynamoDB).	Confusion
