HOW TO IMPORT INTO ANKI (macOS)

1. Open Anki.
2. Create a new deck (recommended names):
   - AWS SAA::01 IAM
   - AWS SAA::02 EC2
   - AWS SAA::03 Lambda & Containers
   - AWS SAA::04 S3 & Storage Gateway
   - AWS SAA::05 Databases
   - AWS SAA::06 VPC & Networking
   - AWS SAA::07 Messaging Monitoring Security
   - AWS SAA::08 Patterns Migration Analytics
   - AWS SAA::09 Other Services & Confusions
   - AWS SAA::10 Key Numbers & Practice Tips

   (Using the :: hierarchy keeps everything neatly nested under one parent deck.)

3. For each file:
   - File → Import
   - Select the .txt file
   - Type: “Text separated by tabs or semicolons”
   - Field separator: Tab
   - Allow HTML in fields: Yes (so line breaks and formatting work)
   - Map the columns:
        Field 1 → Front
        Field 2 → Back
        Field 3 → Tags   (optional but recommended)
   - Choose the correct deck you created above
   - Click Import

4. After importing all files you will have ~260+ high-yield cards covering the entire cheatsheet.

TIPS FOR MAXIMUM LEARNING EFFICIENCY

- Study with Tags: filter by “exam-trap”, “mnemonic”, “QuickRef”, etc.
- Use Anki’s Custom Study → “Study by tag” or filtered decks for weak areas.
- Review the “exam-trap” and “mnemonic” tags more frequently (they are highest-yield).
- The “QuickRef” and “KeyNumbers” cards are excellent for the day before the exam.
- Keep the cards short and answer out loud – active recall is the goal.

These files are plain UTF-8 tab-separated text and work on Anki Desktop (macOS/Windows/Linux) and AnkiMobile.

Good luck on the SAA-C03 exam!
